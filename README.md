# Sistema de Gestão para Estética Automotiva

Trabalho Final – Modelagem de Banco de Dados Completa (2º Bimestre).

O projeto apresenta a modelagem conceitual, lógica e física de um banco de dados para uma empresa de estética automotiva, com implementação em PostgreSQL no Supabase, carga de dados fictícios, operações CRUD e consultas de relatórios.
